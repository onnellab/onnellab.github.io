Android
앱 이름:
Meriq

간단한 설명:
굿즈 제작 데이터를 한곳에서 준비하세요.

랜딩 부제:
굿즈 제작 데이터를 한곳에서 준비

프로모션 텍스트:
이미지 배치부터 칼선, 화이트, 제작 검사와 파일 내보내기까지 한 프로젝트에서 준비하세요.

자세한 설명:
Meriq는 굿즈 제작을 위한 오프라인 생산 준비 앱입니다.

이미지를 가져와 제품이나 캔버스 규격을 정한 뒤, 프론트·백의 아트워크와 제작 레이어를 한 프로젝트에서 정리할 수 있습니다. 제작 미리보기와 기본 제작 검사를 함께 확인하며 작업 흐름을 이어갈 수 있습니다.

## 주요 기능

- 앞면/뒷면 이미지 및 제작 레이어 편집
- 벡터 칼선과 화이트 레이어 준비
- 실제 크기와 해상도를 기준으로 한 기본 제작 검사
- 미리보기 기반으로 내보내기 흐름을 관리
- 투명 PNG, 제작용 PDF 등 지원 형식으로 내보내기
- 실행 취소·다시 실행 지원

## 앱이 아닌 기능

- 계정이나 로그인 없이 사용
- 광고 없음
- 클라우드 동기화 없음
- 사용자가 선택한 파일만 system picker로 접근

랜딩 페이지:
여러 도구를 오가며 파일을 정리하지 말고, Meriq로 프로젝트별로 굿즈 제작용 파일을 한 곳에 정리하세요.

이미지 배치부터 칼선·화이트·후가공 레이어, 그리고 제작 검사까지 하나의 프로젝트에서 처리할 수 있어 초보자도 부담 없이 출력을 준비하기 쉽습니다.

자주 묻는 질문:
질문: 프로젝트 파일이나 이미지가 서버로 전송되나요?
답변: 아니요. 프로젝트와 가져온 리소스는 기기 로컬에만 저장됩니다. 미리보기/내보내기/공유는 사용자가 선택한 동작일 때만 수행됩니다.

질문: 스토어 구매는 어떻게 처리되나요?
답변: 구매/복원은 앱스토어 또는 플레이스토어 정책을 통해서만 처리되며, 카드·은행 정보는 앱에 저장되지 않습니다.

질문: 어떤 파일을 내보낼 수 있나요?
답변: 내보내기, 공유, ZIP 프로젝트 패키지 이동은 사용자가 직접 시작할 때만 실행됩니다.
