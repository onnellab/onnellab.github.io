설명:
Meriq is a practical mobile workspace for preparing merch production data.

Import your source image and choose a product or canvas size, then place artwork and working layers in one project. The app is built for prepress flow, including production preview and quick production checks.

## Main features

- Edit front and back artwork and production layers in one workspace
- Prepare vector cut lines and white layers
- Run basic production checks for physical size and image resolution
- Preview before export and preview what your file will produce
- Export supported files such as transparent PNG and production PDF
- Undo and redo while you work

## What it is not

- No account is required
- No ads
- No cloud sync by design
- No file access except from files you intentionally select

Landing page:
Meriq helps you prepare merch production files from start to export without switching tools.

With Meriq, you create one project per design and keep editing and generating production deliverables for that project in one place. Front/back images, production layers, preview, and checks stay together so your workflow stays stable and repeatable.

FAQ:
Q: Does Meriq upload my project files or images?
A: No. Projects and imported resources are stored on the device only. Preview and export happen locally.

Q: Are my files sent to ONNELLAB servers?
A: No. Purchases and restores are processed by the App Store or Google Play; project content is not uploaded.

Q: Can I share or export only when I choose?
A: Yes. Export, share, and ZIP package transfer happen only when you start them.
