앱 이름:
Segra - 오디오 자르기·병합

간단한 설명:
MP3와 WAV 오디오를 자르고, 합치고, 영상으로 만들어요.

랜딩 부제:
오디오 자르기와 병합

자세한 설명:
오디오를 자르고 합치는 도구예요

Segra는 오디오 파일을 자르고, 합치고, 영상으로 만드는 도구예요.
MP3와 WAV 파일에서 필요한 구간만 저장하거나, 여러 오디오 파일을 하나로 이어붙일 수 있어요.

주요 기능
* 오디오 자르기
* MP3 및 WAV 지원
* 시작 지점과 종료 지점 선택
* 필요한 구간만 새 파일로 저장
* 여러 오디오 파일 병합
* 오디오 + 이미지 → MP4 영상 생성
* 원본 파일 보존

필요한 부분만 남겨요

긴 녹음 파일에서 필요한 부분만 잘라 새로운 파일로 저장할 수 있어요.
원본 파일은 수정하지 않으며, 항상 새 파일로 저장해요.

여러 오디오를 하나로 합쳐요

음성 파일이나 녹음 파일을 원하는 순서로 이어붙일 수 있어요.
내레이션, 오디오북, 팟캐스트, TTS 음성 정리에 활용할 수 있어요.

오디오를 영상으로 만들어요

오디오 파일과 이미지를 결합하여 MP4 영상으로 저장할 수 있어요.
유튜브 업로드용 음성 영상이나 정적인 배경 영상을 간단하게 만들 수 있어요.

안전한 오프라인 처리

Segra는 완전한 오프라인 오디오 도구예요.

* 로그인 없음
* 계정 생성 없음
* 파일 업로드 없음
* 광고 및 추적 없음

모든 작업은 사용자 기기 내에서만 처리해요.

Segra는 복잡한 오디오 편집기 대신, 필요한 구간을 자르고 정리하는 데 집중한 조용한 오디오 도구예요.

랜딩 페이지:
Segra는 MP3·WAV 파일을 자르고, 여러 오디오 파일을 이어 붙이거나 오디오와 이미지를 MP4 영상으로 만드는 도구예요.

복잡한 음악 제작보다 자주 쓰는 편집 작업에 집중해요. 긴 녹음에서 필요한 구간만 남기거나 내레이션, 오디오북, 팟캐스트, TTS 음성을 정리할 수 있어요.

## 주요 기능

- 시작점과 종료점을 지정해 MP3·WAV 구간 자르기
- 여러 오디오 파일을 원하는 순서로 병합
- 오디오와 이미지로 MP4 영상 만들기
- 결과를 새 파일로 저장해 원본 보존
- 기기 안에서 오프라인 처리

원본 파일은 수정하지 않고 결과를 새 파일로 저장해요. 로그인, 계정 생성, 파일 업로드, 광고나 추적 없이 기기 안에서 처리해요.

자주 묻는 질문:
질문: 어떤 오디오 작업을 지원하나요?
답변: MP3·WAV 구간 자르기, 여러 오디오 파일 병합, 오디오와 이미지로 MP4 영상 만들기를 지원해요.

질문: 원본 오디오 파일이 바뀌나요?
답변: 아니요. 잘라내거나 병합한 결과는 새 파일로 저장하고 원본은 그대로 둬요.

질문: 녹음 파일을 MP4 영상으로 만들 수 있나요?
답변: 네. 오디오 파일에 이미지를 결합해 간단한 MP4 영상을 만들 수 있어요. 내레이션, 팟캐스트, TTS 음성 등을 영상으로 준비할 때 사용할 수 있어요.

질문: 파일을 서버로 업로드하나요?
답변: 아니요. 로그인이나 파일 업로드 없이 기기 안에서 처리해요.
