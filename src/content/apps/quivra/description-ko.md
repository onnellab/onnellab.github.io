랜딩 페이지:
Quivra는 WAV, M4A, MP4, MOV 파일을 정해진 규칙으로 변환하는 미디어 변환 도구예요.

파일을 선택하면 입력 형식에 맞춰 변환 방식을 자동으로 정해요. 시작 전에 복잡한 출력 옵션을 고를 필요가 없어요.

## 주요 기능

- WAV를 MP3로 변환
- M4A를 MP3로 변환
- MP4 영상에서 MP3 오디오 추출
- MOV 영상을 MP4로 변환
- 입력 형식에 맞는 변환 자동 선택
- 저장 위치 기억과 같은 이름의 파일 자동 구분

원본은 그대로 두고 변환 결과를 새 파일로 저장해요. Quivra는 일회성 구매로 이용하는 유료 앱이며 광고나 구독이 없어요.

자주 묻는 질문:
질문: 어떤 변환을 지원하나요?
답변: WAV·M4A를 MP3로 변환하고, MP4 영상에서 MP3 오디오를 추출하거나 MOV 영상을 MP4로 변환할 수 있어요.

질문: 출력 형식을 직접 골라야 하나요?
답변: 아니요. 입력 파일 형식에 따라 변환 방식을 자동으로 선택해요.

질문: 원본 파일이 바뀌나요?
답변: 아니요. 원본은 그대로 두고 변환 결과만 새 파일로 만들어요.

질문: 저장 위치를 매번 다시 골라야 하나요?
답변: 아니요. 한 번 선택한 저장 위치를 기억하고, 같은 이름의 파일이 있으면 자동으로 구분해 저장해요.
