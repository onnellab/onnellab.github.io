랜딩 부제:
일괄 파일명 정리

자세한 설명:
Aligna는 파일 이름을 규칙에 따라 깔끔하게 정리하는 일괄 파일명 변경 도구예요.

사진, 음악 파일, 문서처럼 이름을 반복해서 바꿔야 하는 파일들을 빠르게 정리할 수 있어요. 변경 전 미리보기를 확인한 뒤 적용할 수 있어 실수 없이 사용할 수 있어요.

주요 기능

• 파일 이름 앞에 날짜 추가
• 파일 이름 뒤에 날짜 추가
• 연속 번호 추가
• 공백을 언더스코어로 변환
• 금지 문자 제거
• 촬영일 기준 사진 정리
• Artist - Title 형식으로 MP3 이름 정리
• Track - Title 형식으로 MP3 이름 정리
• 적용 전 미리보기 제공
• 여러 파일 일괄 이름 변경

Aligna는 파일 탐색기나 클라우드 관리 앱이 아니에요. 파일 이름을 빠르고 일관성 있게 정리하는 데 집중한 조용한 유틸리티예요.

## 주요 기능

- 날짜 붙이기
- 연속 번호 붙이기
- 공백을 밑줄로 바꾸기
- 금지 문자 정리
- 촬영일 기준 사진 이름 정리
- 아티스트·트랙 번호·제목으로 음악 파일 이름 정리
- 적용 전 새 파일 이름 미리보기

계정, 광고, 클라우드 저장 없이 기기 안에서 처리해요. Android에서는 선택한 파일 이름을 바꾸고, iOS에서는 원본을 직접 바꾸지 않고 새 이름의 사본으로 저장해요.

자주 묻는 질문:
질문: 어떤 규칙으로 파일 이름을 바꿀 수 있나요?
답변: 날짜나 연속 번호를 붙이고, 공백과 금지 문자를 정리할 수 있어요. 사진 촬영일이나 음악의 아티스트·트랙 번호·제목 정보로 이름을 맞출 수도 있어요.

질문: 원본 파일 이름을 직접 바꾸나요?
답변: Android에서는 선택한 파일 이름을 바꿀 수 있어요. iOS에서는 시스템 제한으로 원본과 별도로 새 이름의 파일을 저장해요.

질문: 변경될 이름을 미리 볼 수 있나요?
답변: 네. 변경을 적용하기 전에 새 파일 이름을 확인할 수 있어요.

질문: 파일을 서버로 업로드하나요?
답변: 아니요. 계정이나 클라우드 저장 없이 기기 안에서 처리해요.
