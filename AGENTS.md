# ONNELLAB website

## Content and search discovery

Read the relevant original instructions in [onnellab/onnel-content-engine](https://github.com/onnellab/onnel-content-engine) before planning changes to a public brand homepage, product landing page, or search discovery. Use the existing local checkout on its default branch when available. Otherwise, open the linked files on GitHub.

- For public brand and product pages, buyer-facing copy, and acquisition experiments, read [global-micro-saas](https://github.com/onnellab/onnel-content-engine/blob/main/.claude/skills/global-micro-saas/SKILL.md). For `/ondo-paper/`, also read [ONDO PAPER operations](https://github.com/onnellab/onnel-content-engine/blob/main/projects/ondo-mungu/OPERATIONS.md) for the brand's publication and 28-day measurement criteria.
- For a new or substantially updated public page, or changes that affect indexing, read the content engine's [Search Discovery Runbook](https://github.com/onnellab/onnel-content-engine/blob/main/docs/Search_Discovery_Runbook.md). Apply this repository's [search discovery deployment contract](docs/search-discovery.md) when changing the sitemap, robots policy, or IndexNow integration.

The content engine owns the editorial, measurement, and search submission procedures. This repository owns website implementation and deployment.
