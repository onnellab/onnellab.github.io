# ONNELLAB website copy guide

## Purpose
Keep ONNELLAB pages factual, approachable, and specific to each product. The site is a product directory, not a collection of inspirational slogans.

## Headings and descriptions
- Start with the actual task, file type, or result: “Edit MP3 and FLAC tags”, not “Make your music collection your own”.
- Prefer plain statements and concrete nouns over metaphors about journeys, connections, experiences, possibilities or care.
- Do not build rhythm by stacking three abstract verbs (“create, connect and share”) or adding unnecessary commas and dashes.
- Avoid unsupported speed claims, superlatives, promises of reliability, and comparisons not backed by testing.
- Do not repeat the same broad philosophy in every section. Use homepage space for app discovery, supported platforms, file-handling details and links to product pages.
- Keep descriptions short without making them vague. Name meaningful file formats and platform differences only when verified.
- Do not invent capabilities. Review each product page or implementation before making a claim. Separate paid features from free features.
- A visible user benefit is welcome when it follows from a real feature; decorative sentiment is not.

## Korean
- Use natural -해요 style in explanatory prose. Short noun-phrase headings are also fine.
- Avoid forced parallel slogans such as “작지만 강력한”, “한 번의 터치로 이어지는”, “더 나은 경험을”.
- Preferred: “MP3·FLAC 태그를 편집해요.” / “저장한 음악을 폴더별로 재생해요.”

## Translation
- Apply this editorial intent to en, ko, ja, zh-Hans, zh-Hant, pt-BR, de, fr and es.
- Write idiomatic local copy; do not translate metaphors literally or impose Korean sentence rhythm on other languages.
- Verify that important feature claims and Free/Pro distinctions agree across locales.

## Scope and review
- Update copy in the source of truth, not only in generated HTML.
- Preserve semantic meaning needed by search, SEO descriptions, accessibility labels and product-specific tests.
- When changing homepage headings, update localized regression tests as part of the same change.
- This guide covers promotional and product text; legal documents and privacy notices must prioritize precision.
